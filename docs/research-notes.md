# Research Notes

## Research question

Can commonly-used classical ML models (linear/logistic regression, tree
ensembles, gradient boosting, SVM) meaningfully distinguish academically
at-risk students from their peers using only current-semester assessment
data, attendance, and GPA history — and does model complexity actually help?

## Dataset

**Entirely synthetic** — `data/synthetic/students_synthetic_v1.csv`, 3,000
rows, generated by `scripts/generate_dataset.py` (seed 42). Every
relationship (attendance → performance, previous GPA → current outcome,
etc.) is hand-specified with documented weights plus Gaussian noise; see
the script's docstring for the exact rationale per feature. **These results
say nothing about real institutional performance** — see
[docs/machine-learning.md](machine-learning.md)'s Known Limitation section.

## Methodology

1. Generate synthetic data with a documented, weighted-linear-plus-noise
   ground truth (deliberately imperfect — R² ≈ 0.76 is the practical
   ceiling given the injected noise, not a modeling failure).
2. 80/20 stratified train/test split (stratified on the classification
   target so the ~8% minority class is represented in both splits).
3. Fit one shared preprocessing pipeline on the training split only.
4. Train 5 classifiers and 3 regressors with identical splits/preprocessing
   so comparisons are apples-to-apples.
5. Evaluate on the held-out test split only; select production models by
   macro-F1 (classification) and R² (regression) — not raw accuracy.

## Experimental setup

- scikit-learn 1.9.1, XGBoost 3.4.1, SHAP 0.52.0 (see `requirements.txt`
  for the full pinned environment).
- `sample_weight = compute_sample_weight("balanced", y_train)` applied
  uniformly across all classifiers to address class imbalance.
- Random state fixed (42) throughout for reproducibility.

## Results

See [docs/model-evaluation.md](model-evaluation.md) for the full table.
Headline: **Logistic Regression outperformed every tree-based/ensemble
model on macro-F1** (0.681 vs. 0.664 for the next-best, Random Forest).

## Error analysis

From the selected classifier's confusion matrix (reproduced in
model-evaluation.md): the model's largest error mode is confusing "Average"
and "Good" (78 "Average" students predicted as "Good", 70 "Good" students
predicted as "Average") — expected, since these two categories sit on
either side of a single GPA threshold (3.0) with continuous, noisy inputs
feeding them; a student near that boundary is genuinely hard to classify
correctly, by construction. The "At Risk" class, by contrast, is well
separated (only 7 of 47 misclassified) — likely because it sits at the
extreme low end of the GPA distribution, where the injected noise has less
room to push a student across a class boundary.

## Limitations (research-specific, beyond the general ones in the README)

- **No real institutional data** — this is the single biggest limitation
  of the "research" component; every numeric result here is a property of
  the synthetic generator, not evidence about real students.
- **No hyperparameter search** — results reflect reasonable defaults, not
  each model's best achievable performance; the relative ranking between
  models could shift with tuning (though the qualitative conclusion —
  linear signal favors linear models — would likely hold, since it follows
  from how the data was generated, not from under-tuning).
- **Single train/test split, no cross-validation** — a k-fold CV would give
  a variance estimate around these point metrics; not done here for time,
  documented as a gap rather than silently omitted.
- **Synthetic feature independence may be unrealistic** — real assessment
  types (quiz/assignment/midterm/etc.) are likely more correlated with each
  other than the independent-noise construction here assumes.

## Future work

- Re-run this exact pipeline against a real (properly anonymized,
  IRB-appropriate) institutional dataset once available, and compare
  whether the "simpler model wins" result holds.
- Add k-fold cross-validation and a hyperparameter search (grid or
  Bayesian) per model.
- Compare `sample_weight`-based imbalance handling against SMOTE/other
  resampling techniques.
- Extend the regression task to interval/quantile predictions (e.g.
  predicted GPA ± confidence interval) rather than a point estimate, to
  better communicate uncertainty to students.
